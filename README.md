## 🎯 Sobre

Coleção de **scripts Python independentes** para praticar aplicações web básicas, automação local, jogos e manipulação de dados. Não é um projeto único com infraestrutura compartilhada.

## 📚 Scripts incluídos

| Arquivo | Objetivo |
|---|---|
| [`Main.py`](Main.py) | Calculadora web com formulários Flask |
| [`iniciar.py`](iniciar.py) | Automação local para abrir aplicativos no Windows |
| [`jogoChunck.py`](jogoChunck.py) | Protótipo de jogo com Pygame |
| [`push.py`](push.py) | Extração de documentos JSON para arquivo CSV |
| [`search.py`](search.py) | Busca de registros em dados JSON |

## 🚀 Exemplos de execução

Para experimentar a calculadora Flask em ambiente local:

```bash
git clone https://github.com/WalterMatheusgg/Projects_Py_Aleatorios.git
cd Projects_Py_Aleatorios
python3 -m venv .venv
source .venv/bin/activate
python -m pip install flask
python Main.py
```

Para o protótipo de jogo, instale `pygame` no seu ambiente e execute `python jogoChunck.py`.

**Atenção:** alguns scripts contêm caminhos locais específicos de Windows ou marcadores de diretórios; ajuste-os antes da execução. Os exemplos não foram preparados para implantação pública, uso com dados sensíveis ou tratamento completo de exceções.
